## 1. 프로젝트 소개

매년 설날과 추석에는 전국 단위 대이동이 발생하고, 이 기간에 교통사고가 집중됩니다.
그런데 "설날과 추석 중 어느 쪽이 더 위험한가"라는 질문에 바로 답해 주는 화면은 없습니다.
사고 통계는 연도별·지역별로 흩어져 있고, 설날과 추석을 **같은 기준으로 나란히 비교**해 주는 자료는 찾기 어렵습니다.

본 프로젝트는 이 질문에서 출발했습니다.

> **"설날 vs 추석, 어느 명절이 더 위험한가"**
> 데이터: 명절 사고 2022~2024
> 화면: 설과 추석을 좌우로 비교하는 대시보드 — 사고 건수, 사망자, 부상자, 연도별 변화를 보여줍니다.

- **프로젝트명** : 명절 연휴 교통사고 대시보드 (설날 vs 추석)
- **한 줄 소개** : 명절 연휴 교통사고 데이터를 연도·지역·용도 기준으로 통합 조회하고, 설날과 추석을 같은 축 위에서 비교하는 데이터 분석 서비스
- **분석 기준** : 이륜차 포함, 전체 차량 기준
- **팀** : SKN37기 4조

## 2. 주제 선정 이유

### 데이터 관점

| 데이터 | 특성 | 활용 목적 |
|---|---|---|
| 설날·추석 연휴 사고 통계 (2021~2025) | 연휴별 정량 수치 (사고 건수·사망·부상) | 명절 간 위험도 직접 비교 |
| 연휴기간별 교통사고 다발지역 (2017~2024) | 반경 100m / 대상사고 4건 이상 다발지 | 사고 집중 지점 파악 |
| 차량 등록 현황 (기간·지역·용도) | 사륜·이륜 구분 등록 대수 | 사고를 등록 규모와 함께 해석 |
| 보험사 FAQ | 사고 처리 관련 Q&A 텍스트 | 사고 이후 실제 대응 안내 연결 |

통계 수치만 보여주면 "그래서 어디가 위험하고 어떻게 해야 하나"에 답하지 못합니다.
그래서 **사고 통계(무엇이 얼마나) + 다발지역(어디서) + FAQ·안내(어떻게)** 를 한 흐름으로 묶었습니다.

### 주제 확정 과정 (팀 내 검토 기록)

프로젝트 주제가 "전국 자동차 등록 현황 및 기업 FAQ 조회 시스템"으로 잡혀 있었지만, 핵심은 등록 현황입니다.
설득력이 떨어지는 데이터를 우리하게 엮기보다는 **완벽하게 정합성이 맞는 데이터만으로 밀도 있게 구성하는 것이 훨씬 완성도 높습니다.**

- **컨셉 후보** : "배달·상업용 이륜차 급증에 따른 지역별 사고 위험도 및 관리 대시보드 (22~24)"
- **구성**
  1. **[등록]** 22~24년 지역별 / 용도별(가정용 vs 영업용) 등록 대수 추이
  2. **[사고]** 22~24년 지역별 사고 발생 수 및 위험지수(등록 대수 대비 사고 비율)
  3. **[FAQ]** 이륜차 등록 / 검사 / 의무보험 법률 관련 FAQ
- **장점** : 연도 축이 22~24년으로 완전히 일치하여 시각화 차트나 메시지의 설득력이 가장 깔끔하고 단정적입니다.

![주제 확정 검토 기록](https://www.genspark.ai/api/files/s/1D1VTSoP)

*▲ 주제 후보 비교 및 연도 축 정합성 검토 기록*

### 프로젝트 전략

- 연도를 **2022~2024(명절 사고) / 2021~2025(연휴 사고통계)** 로 명확히 고정해 비교 축을 흔들지 않습니다.
- 설날과 추석을 **동일 집계 기준**으로 맞춘 뒤 비교합니다.
- 수집만 하고 끝내지 않고, 모든 수집 항목에 대해 **사용 / 미사용 여부와 사유를 문서로 남깁니다.** (→ [4. 수집 데이터 활용 현황](#4-수집-데이터-활용-현황))

## 3. 주요 기능

### 📊 대시보드 (메인)

- 설날과 추석을 **좌우 2단으로 배치한 비교 화면**
- 사고 건수 비교
- 사망자 수 비교
- 부상자 수 비교
- 연도별 변화 추이
- 연휴 기간 대비 일평균 사고 환산(연휴 일수 차이 보정)

### 🗺️ 지도 화면 — 등굣길 옆 이륜차 사고다발지

- 최근 3년 이륜차 사고다발지와 전국 어린이보호구역을 **한 지도에 중첩**
- 사고다발지 반경(슬라이더) 안에 들어간 보호구역을 자동 탐색
- 지역·시설 종류(초등학교·유치원·어린이집·특수학교·학원) 필터
- 사고다발지 반경 밖 보호구역 / CCTV 미설치 보호구역 구분 표시
- 사고다발지 클릭 시 사고 건수·사상자 구성·반경 내 보호구역 목록 표시

![등굣길 옆 이륜차 사고다발지 화면](https://www.genspark.ai/api/files/s/hWhFTgEX)

*▲ 이륜차 사고다발지(적색 원) + 반경 내 어린이보호구역(노란 점) + 미포함 보호구역(회색 점) 중첩 지도*

### 🚗 자동차 등록 현황 화면

- 기간(연월) / 지역(도시·군·구) / 차량용도 3개 축으로 등록 대수 조회
- 사륜·이륜 구분 조회
- 등록 대수 추이 시각화

### ❓ FAQ

- 보험사 FAQ 조회 (삼성화재·하나·AXA)
- 소형 모빌리티(이륜차·PM) FAQ
- 사고 접수·보상 절차 안내

## 5. 데이터 해석 시 주의사항

- 설날·추석은 **연휴 일수가 매년 다릅니다.** 총 사고 건수만 비교하면 연휴가 긴 해가 불리하므로 **일평균 환산**을 함께 봐야 합니다.
- 사고 통계의 집계 기준(사고 발생일 기준 / 신고일 기준)이 연도별로 다를 수 있습니다.
- `koroad` 다발지역은 **반경 100m 내 대상사고 4건 이상**이라는 선정 조건이 있는 데이터로, 조건에 들지 않은 지역은 표시되지 않습니다.
- 다발지역의 위치는 대표 좌표이므로 실제 사고 지점과 수십 m 차이가 날 수 있습니다.
- 이륜차 데이터는 **이륜차만 따로 본 화면**이며, 전체 차량 기준 대시보드와 모집단이 다릅니다.
- FAQ는 각 사의 공식 안내를 크롤링한 텍스트로, **보상 판단의 근거가 될 수 없습니다.** 정확한 내용은 원문 링크에서 확인해야 합니다.
- 지도 화면의 CCTV 미설치 보호구역은 수집 시점 기준이며, 이후 설치·변경될 수 있습니다.
- 등록 대수는 **Stock(누적)**, 사고 건수는 **Flow(기간 발생)** 로 성격이 다르므로 단순 비율(사고율)을 만들지 않습니다.

## 10. 실행 방법

```bash
git clone <repository-url>
cd SKN37-1st-4Team

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 만들고 DB 접속 정보를 설정합니다.

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=YOUR_DB_USER
DB_PASSWORD=YOUR_DB_PASSWORD
DB_NAME=YOUR_DB_NAME
```

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속.

> ⚠️ DB 비밀번호·API 키 등 민감 정보는 저장소에 올리지 않고 `.env`로만 관리합니다.

## 12. 향후 계획

- 명절뿐 아니라 **여름휴가철·설 연휴 전후 주말**까지 비교 범위 확대
- 연휴 일수 보정(일평균 환산) 로직을 화면 옵션으로 제공
- 사고다발지 × 보호구역 × CCTV 데이터를 **위험 등급**으로 정리해 한 지도에서 우선순위 확인
- 데이터 갱신 자동화 (수집 → 전처리 → DB 적재 파이프라인)
- FAQ를 사고 유형별로 분류해 대시보드에서 바로 연결
